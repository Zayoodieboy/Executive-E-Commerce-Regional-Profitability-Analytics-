# Executive E-Commerce & Regional Profitability Analytics

## 💼 Business Context & Problem Statement
* **Company:** Global E-Commerce & Multi-Region Retail Enterprise
* **The Problem:** The enterprise experienced strong top-line revenue growth, yet bottom-line profit margins were contracting unpredictably across specific product categories, shipping corridors, and states. Leadership lacked granular visibility into whether margin decay stemmed from operational fulfillment delays or aggressive promotional discounting.
* **The Objective:** Build an end-to-end data pipeline using **Python** for programmatic data cleansing and feature engineering, followed by an interactive **Tableau** C-suite dashboard that pinpoints regional profit leakage and evaluates discount elasticity.

---

## 🛠️ Tech Stack & Tools
* **Data Processing & Engineering:** Python (`Pandas`, `NumPy`)
* **Data Visualization & BI:** Tableau Desktop
* **Data Pipeline:** Raw enterprise transactions cleaned via Python script $\rightarrow$ Exported to Master CSV $\rightarrow$ Visualized in Tableau.
* **Version Control:** Git & GitHub

---

---

## 📊 Data Schema & Master Table Structure
The underlying dataset processed by Python and ingested into Tableau adheres to the following schema:

| Column Name | Data Type | Description |
| :--- | :--- | :--- |
| `Order ID` | String | Unique transaction identifier |
| `Order Date` | Date | Timestamp of customer order placement |
| `Ship Date` | Date | Timestamp of order fulfillment |
| `Region` | String | Geographic sales territory (`East`, `West`, `Central`, `South`) |
| `Category` | String | Major product grouping (`Technology`, `Furniture`, `Office Supplies`) |
| `Sales` | Float | Total dollar revenue generated by the order |
| `Discount` | Float | Promotional discount percentage applied to the transaction |
| `Profit` | Float | Net earnings after subtracting cost of goods sold and discounts |
| `Profit Margin Ratio` | Float | Engineered metric (`Profit / Sales`) |
| `Shipping Days` | Integer | Engineered fulfillment turnaround time in days |

## 🚀 Key Business Insights & Impact
1. **The 20% Discount Threshold:** Transaction-level analysis confirms that discounts exceeding 20% convert high-volume sales into net financial losses.
2. **Regional Fulfillment Inefficiencies:** Certain high-revenue states experience severe margin compression caused by prolonged shipping turnaround days combined with local discounting.
3. **Strategic Action:** Recommended restricting local discounting authority above 15% in underperforming regional markets and auditing shipping logistics to protect the bottom line.
